CodeClear review demonstrations

Accessibility and supported system alerts

This 85-second recording uses a validation build, an Android emulator and synthetic drill messages. It demonstrates user consent and visible system alert observation. It does not establish physical radio reception, universal device support or translation accuracy.

Recording sequence

  1. Read the separate accessibility disclosure; cancel without granting access.
  2. Reopen the disclosure and explicitly enable access in Android settings.
  3. Review and separately grant notification access. Remote and local translation remain off.
  4. Trigger a synthetic message through the system receiver. Its original warning remains visible.
  5. Inspect the captured original in CodeClear history without dismissing the system warning.

CodeClear observes supported emergency-alert source screens to recover original messages for the user's history and chosen translation engine. Access can be withdrawn in Android settings. Production collection does not require ADB or the fixture used to make this recording.

Connected-device foreground service

The first chapter was recorded on November 5, 2026, using version code 4 on an Android 17 phone. It shows the visible Settings → Labs entry, separate sharing disclosure, cancellation, actual Nearby devices permission, and service operation while another app is visible, followed by stopping sharing. Capture and translation remain off. The second chapter is earlier physical Bluetooth evidence from November 3, using version code 3 on a phone and tablet with synthetic originals. Each chapter identifies its source version and date. This is not a new two-device test of version code 4 or 5. Version code 5 retains the demonstrated UI and only changes optional hardware declarations and build number.

Android 11 Bluetooth discovery permissions

This 29-second Android 11 emulator recording from November 5 uses version code 4. It shows the separate disclosure, cancellation, and actual Android location prompt with While using the app selected. Background location access is not requested; sharing pauses when the app is no longer visible. No location coordinates are collected. Version code 5 retains this permission flow. This demonstrates permission controls, not physical Bluetooth or cellular reception. Android 12 and later use Nearby devices access instead of location access.
