재난문자 수집과 기기 내 기록

앱 내 별도 설명에 동의하고 Android 알림 접근을 허용하면, CodeClear는 검토된 시스템 재난문자 수신 앱의 메시지를 선별합니다. Android 알림 접근으로 다른 알림도 서비스에 전달될 수 있지만 관련 없는 알림은 보관하지 않습니다. 접근성도 별도로 동의·허용해야 하며, 검토된 시스템 경보 창의 개별 본문 필드·제목·대기 건수를 읽습니다. 버튼을 누르거나 시스템 경보를 닫지 않으며 스크린샷을 기록하지 않습니다. 장애인 보조 기능을 제공하는 접근성 도구는 아닙니다.

기록에는 원문·제목, 수집 출처·시각, 확인 가능한 경보 유형 근거, 개별 수집 이력과 번역이 포함됩니다. 원문 자체에 이름·전화번호·주소 등 개인정보가 들어 있을 수 있습니다. 같은 원문은 묶되 개별 수집 이력은 보존합니다. 설정과 모델 준비 상태도 기기에 저장합니다. 앱 계정은 필요 없으며 SMS 받은편지함·연락처·마이크·카메라를 읽지 않습니다.

기록은 삭제할 때까지 앱의 비공개 저장 공간에 남습니다. 앱 데이터 백업과 기기 간 전송은 꺼져 있습니다. 비공개 앱 저장 공간을 사용한다는 뜻이며 데이터베이스 전체가 별도로 암호화된다는 뜻은 아닙니다. 원문과 묶인 번역·수집 이력을 삭제하거나 전체 기록 또는 Android 설정의 앱 저장 공간을 지울 수 있습니다. 수집을 끄면 새 수집이 멈추며 기존 기록은 유지됩니다.

기기 내 번역과 언어 모델

ML Kit은 필요한 모델 준비를 허용한 뒤 기기 안에서 원문을 번역합니다. 모델 다운로드에는 인터넷이 필요합니다. Google SDK는 기기·앱 정보, 설치 식별자, 성능·오류 이벤트, 식별되거나 설정된 언어 등 진단·사용 정보를 수집합니다. 기기 내 번역이 SDK의 네트워크 데이터 전송까지 없다는 뜻은 아닙니다. ML Kit 데이터 공개 안내와 Google 개인정보처리방침을 확인하세요.

호환되는 Android 시스템 번역을 켜면 설치된 시스템 번역 서비스에 Android의 기기 내 번역 API로 텍스트를 전달합니다. 지원 언어와 준비 상태는 해당 서비스에 따라 다르며 제공자의 데이터 처리 방침도 적용됩니다.

선택형 온라인 번역

실험실의 온라인 번역은 서비스별로 별도 허용하기 전까지 꺼져 있습니다. 허용한 온라인 엔진을 선택하면 새로 수집한 재난문자나 요청한 기록·주변 메시지 번역에 원문과 번역 언어 정보가 HTTPS로 전송될 수 있습니다. 온라인 엔진으로 자동 전환하지 않습니다. 허용을 철회하면 새 요청이 멈추지만 이미 전송한 내용은 회수할 수 없습니다.

MyMemory(Translated). 원문·언어 쌍과 네트워크 IP 주소 등 연결 정보를 받습니다. 제공자 약관은 전송한 문장을 장기 보관하고 번역 협력사가 서비스를 제공하거나 개선하는 데 처리할 수 있다고 설명합니다. 익명 연동에서는 MyMemory 계정·API 키를 요구하지 않으며 해당 제공자 데이터를 지우는 앱 내 삭제 API는 없습니다. MyMemory 약관과 개인정보 안내를 확인하세요.

CodeClear 서비스와 Groq. 설정된 빌드에는 별도로 제공받은 서비스 접근 코드가 필요한 고정 CodeClear 번역 서비스가 표시될 수 있습니다. 서버는 원문·대상 언어·인증 정보를 받고 추론 요청을 Groq로 전달합니다. 기기에 저장한 접근 코드는 Android Keystore 기반 암호화로 보호하며 Groq 제공자 API 키와는 다릅니다.

서버 캐시는 인증된 클라이언트 범위로 분리되며 공개 번역 자료실이 아닙니다. 원문, 검증한 번역·발신 주체 필드, 모델·프롬프트 정보, 측정한 처리 시간, 제한된 사용량 정보와 생성·만료 시각을 저장합니다. 같은 요청의 중복 번역을 줄이는 용도입니다. 캐시 결과는 생성 후 최대 30일 내 만료하며 재사용으로 만료를 연장하지 않습니다. 본문 없는 요청 제한·삭제 세대 기록은 남용을 막고 늦게 끝난 요청이 삭제한 캐시를 복구하지 못하게 합니다.

호스팅·네트워크 인프라는 서비스를 제공하고 보호하기 위해 IP 주소와 일반적인 요청 메타데이터를 처리합니다. 운영 로그·백업 사본의 보관은 활성 번역 캐시의 만료와 별개입니다. 캐시 만료가 모든 인프라 사본의 실제 삭제를 보장하지는 않습니다. 이 기록은 서비스 운영·보안·남용 방지와 해당 법적 의무를 위해 이용합니다. 사본의 보관에 관한 문의나 열람·삭제 요청은 개인정보 메일로 보내시되 접근 코드를 포함하지 마세요.

접근 코드가 남아 있을 때 앱의 별도 서버 캐시 비우기를 실행해 인증 범위의 삭제를 요청할 수 있습니다. 전송 중지, 로컬 기록 삭제, 접근 코드 제거만으로 서버 캐시가 지워지지는 않습니다. 같은 서비스 인증 정보를 쓰는 기기는 같은 캐시 범위를 쓸 수 있습니다. 삭제 기능에 접근할 수 없다면 접근 코드를 보내지 말고 개인정보 문의 메일로 연락하세요. CodeClear 캐시 삭제로 이미 Groq가 처리한 사본까지 지울 수는 없습니다.

Groq는 추론 입출력을 기본적으로 보관하지 않지만 안정성·남용 조사에 최대 30일, 법적 의무가 있으면 더 오래 보관할 수 있다고 안내합니다. 사용량 메타데이터는 별도로 보관합니다. 계정 설정에 따라 달라지므로 CodeClear는 Zero Data Retention이 켜져 있다고 주장하지 않습니다. Groq는 보관되는 고객 데이터가 미국에 저장된다고 안내합니다. Groq 데이터 처리 안내를 확인하세요.

주변 공유·알림·음성

선택형 Bluetooth 공유에는 실험실 동의와 Android 권한이 필요합니다. 보내기를 켜면 주변 CodeClear 사용자가 새로 수집한 원문·제목·시각과 임시 무작위 수집 식별자를 받을 수 있습니다. 주변에서 읽도록 제공하는 정보이므로 비밀 메시지 통신 수단이 아닙니다. 받은 메시지는 출처가 검증되지 않았으며 삭제 전까지 비공개 주변 기록에 저장하고 다시 전달하지 않습니다. GPS 좌표는 수집하지 않습니다. Android 11은 Bluetooth 검색에 위치 권한과 위치 서비스가 필요하고 백그라운드 동작에는 별도 위치 권한이 필요합니다.

번역 알림과 선택형 앱 오버레이에 원문·번역이 표시될 수 있습니다. 알림과 잠금 화면의 공개 범위는 Android 설정에 영향을 받습니다. 복사·공유를 선택하면 고른 내용이 클립보드 또는 선택한 앱에 전달되며 이후에는 받는 앱의 처리 방침이 적용됩니다.

음성 읽기는 사용자가 시작하며 선택한 설치 음성 서비스에 텍스트를 전달합니다. CodeClear는 네트워크가 필요 없다고 보고된 설치 음성을 선택하고 온라인 전용 음성으로 전환하지 않습니다. 음성 서비스 자체의 구현과 개인정보 처리는 해당 제공자가 담당합니다.

문의·보호·선택권

CodeClear에는 광고나 자체 광고 프로필이 없습니다. 선택형 서비스와 SDK 진단 수집은 위에 설명되어 있으며 데이터 수집이 전혀 없다는 뜻은 아닙니다. Android 권한·비공개 저장 공간을 사용하며 원격 번역은 HTTPS로 연결합니다. 주변 공유는 앞서 설명한 주변 공개 방식입니다.

고객지원에 이메일을 보내면 이메일 주소와 직접 보내신 내용을 문의·개인정보 요청 처리에 이용합니다. 꼭 필요한 내용으로 별도 합의하지 않았다면 실제 재난문자 본문·접근 코드·제공자 키를 보내지 마세요.

문의 메일은 요청 처리와 필요한 후속 응대 또는 법적 의무를 위해 필요한 동안 보관합니다. 개인정보 문의 메일로 삭제를 요청할 수 있습니다. CodeClear는 만 13세 이상 사용자를 위한 일반 안전 보조 도구이며 나이·개인 프로필·아동 계정 정보를 요구하지 않습니다.

Android 알림·접근성 접근을 철회하거나 번역 서비스별 허용, 주변 공유를 끌 수 있습니다. 다운로드 모델·로컬 기록·인증된 서버 캐시를 삭제하거나 앱 저장 공간을 지우고 앱을 제거할 수 있습니다. 기기에서 지워도 외부 제공자나 공유받은 앱의 데이터까지 삭제되지는 않습니다. CodeClear 운영 서비스의 열람·삭제 문의는 개인정보 메일로 보내되 비밀 인증 정보를 보내지 마세요.
